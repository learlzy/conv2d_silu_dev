====================================== yolov8s_subgraph =======================================
- 编译计算图：
atc --framework=5 --model=../yolov8s_subgraph.onnx \
--input_format=NCHW --input_shape="images:8,3,640,640" \
--soc_version=Ascend910B3  --output=yolov8s_subgraph

- 输出完整计算图信息json：
atc --mode=1 \
--om=yolov8s_subgraph.om \
--json=yolov8s_subgraph_om.json

- 输出所有阶段的计算图：
cd build
export DUMP_GE_GRAPH=1
atc --framework=5 --model=../yolov8s_subgraph.onnx \
--input_format=NCHW --input_shape="images:8,3,640,640" \
--soc_version=Ascend910B3  --output=yolov8s_subgraph

- 执行推理
python -m ais_bench --loop=1000 --model=yolov5s.om
